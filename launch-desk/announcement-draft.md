Builders, MLH Global Hack Week: Builders Week is officially live online from Friday, November 6, 2026 at 10:00 AM EST through Thursday, November 12, 2026 at 1:00 PM EST. Hosted by Major League Hacking (MLH), this free digital week brings hands-on engineering tracks across four partner ecosystems so student and professional developers can ship working software.

In the GitHub track, you can complete GitHub Skills exercises, configure custom cloud devcontainers with GitHub Codespaces, and build applications with GitHub Copilot. In the SpaceXSI track, you can scaffold mini-apps and benchmark frontier models in Cursor alongside persistent multi-agent workflows in Grok Bot. In the Auth0 track, you can implement Universal Login, Token Vault delegated API access, CIBA asynchronous authorization, and Auth0 FGA document access control. In the Tiger Data track, you can launch auto-partitioned hypertables, connect AI agents via MCP, stream live telemetry dashboards, and run hybrid pgvector searches.

Check in now at https://events.mlh.com/events/14729-global-hack-week-builders-week and submit your challenge builds at https://www.mlh.com/events/global-hack-week-builders-week/challenges before November 12 at 1:00 PM EST.
