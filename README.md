# Grok Bot Workspace: Persistent AI Teammates, Routines, Browser Workflows & Two-Bot Launch Relay

Built for **MLH Global Hack Week: Builders Week** SpaceXSI Grok Bot challenges:

1. **Challenge 3 (Create Your First Grok Bot)**: Configured `Daily Assistant` persistent AI teammate in the sidebar with cloud computer storage.
2. **Challenge 4 (Teach Grok Bot Your First Task)**: Taught `check-campus-events-and-weather` skill with parameterized `search_keyword` and `target_date` inputs, scheduled as a weekday 8:00 AM routine.
3. **Challenge 5 (Build a Campus Opportunities Database)**: Extracted and verified 5 upcoming MLH events from `https://www.mlh.com/seasons/2027/events` into `campus-opportunities.csv` with all 7 required columns sorted chronologically.
4. **Challenge 6 (Teach Grok Bot a Browser Workflow)**: Built `/campus-event-browser-finder` with explicit source logging, minimum 3-result validation, and strict stop-before-registration safeguard (`browser-workflow-result.csv`).
5. **Challenge 7 (Run a Two-Bot Launch Relay)**: Orchestrated `Source Editor` and `Launch Producer` sharing the `launch-desk/` folder (`launch-desk/source-brief.md`, `launch-desk/announcement-draft.md`, `launch-desk/run-of-show.csv`, and `launch-desk/qa-notes.md` with status `Pass`).
